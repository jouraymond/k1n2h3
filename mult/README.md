# 花片小鎮

小二乘法闖關遊戲。依十二年國教數學領域課綱（108 課綱）二年級條目設計，
關卡順序比照教科書單元進度。純靜態網頁，沒有任何建置流程與後端。

## 放進 GitHub Pages

把整個 `mult/` 資料夾丟進 repo，網址就是：

```
https://<帳號>.github.io/<repo>/mult/
```

若 Pages 還沒開：Settings → Pages → Source 選 `main` / `root`。

## 檔案

```
mult/
├── index.html      小鎮地圖（關卡選擇）
├── play.html       闖關畫面，用 ?lv=3 指定關卡
├── stickers.html   貼紙簿
├── parent.html     家長區：熟練地圖、統計、課綱對照、設定
├── css/style.css   全站視覺
└── js/
    ├── data.js       關卡定義、課綱條目、口訣、貼紙
    ├── store.js      進度儲存 + Leitner 間隔重複排程
    ├── ui.js         SVG 插畫（小鎮場景、小夥伴、圖示、彩帶）
    ├── questions.js  各關出題器
    └── game.js       遊戲流程（只有 play.html 載入）
```

所有插圖都是 SVG 程式碼產生的，沒有外部圖檔。唯一的外部資源是 Google Fonts
的 Baloo 2；拿掉那行 `<link>` 也能正常運作，只是數字會換成系統字。

## 課綱對應

| 關卡 | 內容 | 課綱條目 |
|---|---|---|
| 1 數花片 | 幾個一數，建立相同單位量的經驗 | N-2-6 |
| 2 變算式 | 連加變乘法，被乘數 × 乘數 | N-2-6 |
| 3 幾倍呀 | 「倍」的語言 | N-2-6 |
| 4 2 5 4 8 | 二上第一批乘法 | N-2-7 |
| 5 3 6 9 7 | 二上第二批乘法 | N-2-7 |
| 6 10 1 0 | 二下的特別規則 | N-2-7 |
| 7 轉一轉 | 行列模型轉 90 度，乘法交換律 | R-2-3 |
| 8 倒著想 | 12 是幾乘幾，為分裝與平分鋪路 | n-I-4 |
| 9 小鎮大考驗 | 生活情境文字題 | N-2-6 |

第 2 關會把 `3×5` 判為錯（正解 `5×3`），第 7 關才說明兩者的積相同。
這不是矛盾，是課本二上／二下的教學順序：先建立單位量的意義，再談交換律。

## 排程邏輯

每個乘法組合各有一筆紀錄（3×7 與 7×3 共用一筆），分 0～5 盒，
間隔 1／2／4／7 天。答對且 3.5 秒內作答才升盒，答錯降兩盒。
出題時優先挑盒號低、到期、常錯的組合，再加一點隨機避免背順序。

## 修改

- 換關卡名稱、位置、題數 → `js/data.js` 的 `LEVELS`
- 改出題內容 → `js/questions.js`
- 改配色 → `css/style.css` 最上方的 `:root` 變數
- 改小鎮景物 → `js/ui.js` 的 `townScene()`

進度存在瀏覽器 localStorage（key: `huapian.v3`），換裝置不會同步。
